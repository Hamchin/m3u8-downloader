# m3u8 Downloader

ページで再生された動画の m3u8 (HLS) を検出して、mp4 ファイルとしてダウンロードする Chrome 拡張機能です。個人利用を想定しています。

## 使い方

1. このリポジトリを手元の PC に clone します。
2. Chrome で `chrome://extensions` を開き、右上の「デベロッパーモード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」から、このフォルダ（`manifest.json` のある場所）を選択します。
4. 動画のページを開いて再生すると、拡張機能のアイコンに検出件数のバッジが付きます。
5. アイコンをクリックすると検出された m3u8 の一覧が出ます。選ぶと画質の選択（マスタープレイリストの場合）とファイル名の指定ができ、「ダウンロード開始」で mp4 が保存されます。

## 仕様

- 対象は録画済み動画（VOD）のみです。ライブ配信（`#EXT-X-ENDLIST` のないプレイリスト）は対象外です。
- 検出は `chrome.webRequest` で現在のタブの通信を監視して行います。検出結果はタブ単位で保持され、ページ遷移で消えます。
- 取得は拡張機能の権限で行うため、CORS の制約を受けません。ページ側が使った Referer / User-Agent は観測して再現し、Cookie はブラウザの Cookie Jar から自動で付与されます（ffmpeg の `-headers` 指定が必要なケースへの対応）。
- AES-128 暗号化セグメントは、鍵が取得できる場合に復号します。DRM（Widevine 等）は対象外です。
- mp4 化は再エンコードなしの再多重化です。TS セグメントは [mux.js](https://github.com/videojs/mux.js)（`src/lib/mux.min.js`、Apache-2.0）を使い、fMP4（`#EXT-X-MAP`）は初期化セグメントとセグメントの結合で処理します。対応コーデックは H.264 + AAC を前提としています。
- ダウンロードと変換はオフスクリーンドキュメントで実行されるため、ポップアップを閉じても処理は続きます。進捗はポップアップを開き直すと確認できます。

## 既知の制約

- 変換結果はメモリ上に組み立ててから保存します。1 時間超えの動画でも動作は想定していますが、非常に大きなファイルではブラウザのメモリ上限に当たる可能性があります。
- セグメント取得の並行度は 4 です。失敗時の自動リトライは未実装です。
